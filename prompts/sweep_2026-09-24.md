## What each layer's first check is

| Layer | First check |
|---|---|
| singles | profile the lead number: count, nulls, min, median, max, top 10 entities by it |
| pairs | land rate: distinct keys each side, keys on both, and a second field agreeing on a 20-row sample |
| hops | land rate through the crosswalk named in `via`: A keys reaching the bridge, bridge rows reaching C |
| rollups | per ID, how many appear in 2+ of the listed harm tables; top 10 by table count |
| place | roll the lead number to the level, top and bottom 10, and a per-person rate where DIM_COUNTY applies |
| names | top 20 repeated names or addresses, and one bridge attempt with the agreement rate |
| time | events per year, then for the top actor key: activity in one partner table after the event date |

## Lessons from sweep one

- Full table names are `LIBRARY_MARTS.<SCHEMA>.<SCHEMA>__<TABLE>`. The row's `table` field already carries the prefix.
- The scratchpad is shared. Prefix every scratch file with your agent name.
- "Money after date X": check each award's first action date. Contracts R2 has no modification number, so old-contract mods and delivery orders look new.
- Rates: write the denominator down, then split by the obvious mix, such as loan purpose or border vs interior.
- USAspending assistance is NOT capped anymore; CONTRACTS_FULL still is. Use R2 for contract history.
- New trap files: trap-empty-columns-sweep-2026-09-24, trap-money-ceilings-and-repeated-totals, trap-guessed-and-circular-ids, trap-after-date-money-and-rate-denominators.

## Lessons from sweep two

- Compare a group to its own state or peer group, never only to the nation. Bria looked unique; Illinois flags 30% of all homes.
- A "not ceased" or "not closed" flag is not "still alive". Join to the live register before counting active things.
- When a file is cut mid-year, compare the same months across years.
- Never wrap `COUNT(*)` inside a LIMIT probe on a table over 50M rows. One such probe burned five minutes.
- Before spending queries, check `reports/sweep_2026-09-24/*.md` for tables other agents already probed. Reuse their numbers.
- New trap file: trap-sweep-two-2026-09-24.

## The checks that tripped earlier hunts

1. Count a column's distinct values and look at a sample before trusting it. Suppression markers like `#`, `*`, `-999` or `'nan'` hide numbers.
2. After any ID join, check a second field agrees and report the rate. A one-word name match is 8% real.
3. Line up the years on both sides.
4. Read every flag column's values before filtering on it.
5. Never build on absence. Missing data is a loading gap, not a finding.
6. Name the boring explanation for every pattern.

## Marking rows

From the repo root, one call per row, with your agent name:

```
python scripts/ledger.py mark "ROW_ID" dead   "what you checked, and why nothing is there"    --by AGENT
python scripts/ledger.py mark "ROW_ID" probed "what you checked; what's still open"           --by AGENT
python scripts/ledger.py mark "ROW_ID" live   "the number that makes it worth a deeper pass"  --by AGENT
python scripts/ledger.py mark "ROW_ID" skip   "why it isn't worth checking"                   --by AGENT
```

- Notes are bar speak: plain words, the numbers, one line.
- **Live** means a real number points at a story. Don't mark anything `finding`: live rows get a skeptic first.
- Every row you hold must end the sweep marked. If you run out of budget, mark the rest `untouched` with the note "budget".
- The ledger takes a lock on every write, so parallel marks are safe. If a mark says locked, wait and retry.
