Every place in the Library worth looking twice.

Each dot is a table of public records. Each line means the two tables can be meaningfully compared — they file things under the same kind of identifier. Nothing here is a finding; it is a map of where findings could be.

  1. Dots are sources. Size is how many records they hold, colour is the world they come from.
  2. Lines are shared identifiers. Solid means a hard ID like a tax number; faint means only a place or a name — the weakest kind, and off by default.
  3. The Surprise lens scores each pair against pure luck: overlapping far more than chance allows, or far less than it should.
