Don't write marketing/sales copy into artifacts meant for Chris's own hands-on
working use — no hero taglines, no superlative framing ("the creative lever,"
"the richest family"), no pill/badge/chip UI dressing unless it's functionally
interactive (clickable, filters something, previews something). For a personal
working tool, the content itself should carry the value; styled callouts
selling the idea read as an advertisement, not help.

**Why:** After adding a "Configuration Index" section (icon chips, bolded
callout copy) to [[deadspace-and-counterweight]] mid-session on 2026-08-23,
Chris responded: "wtf is this - not even close to helpful or a toolbox - its
an advertisement. do better." The content/research underneath was sound (10
data questions mapped to real chart configurations) — the failure was
presentation register, not substance.

**How to apply:** For reference/working-tool artifacts (not landing pages),
default to plain, dense, functional layout — tables, lists, real content —
over hero sections, taglines, or "look how smart this is" framing. Separately:
when Chris says "toolbox," check whether he means something literally
selectable/interactive (click to pick, live preview, drag) versus a static
reference — don't assume static without asking. Guessing wrong on the
interactivity question twice in a row is what compounded this into a harsh
reaction; one direct clarifying question earlier would have been cheaper than
two wrong builds.
