# NO-GO ZONE

This folder holds things that were tried and retired. It exists so nothing has to be deleted and nothing has to be argued about.

Rules for any session that finds this folder:

- Do not build from anything in here.
- Do not "clean it up," reorganize it, or delete from it.
- Do not re-adopt a rule, a page, or a script from here just because it exists.
- The only reason to open it: "did we try this before, and what happened?"
- When you put something in, add a row to `LEDGER.md`. That's the whole ceremony.
