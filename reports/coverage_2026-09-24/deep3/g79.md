## 1. HISTORY__FED_WPA_SLAVE_NARRATIVES: **dead**

**What it is:** 100 Library of Congress catalog records for **photographs** from the 1930s Federal Writers' Project. Not the interviews.

**Checked [S01, local]:**
- `FORMAT_LABEL` = "photo, print, drawing" on **100 of 100** rows.
- `FULL_TEXT` is the physical description of the print. 18 distinct strings. **70** rows read "1 photographic print : gelatin silver ; 5 x 3 1/4 in."
- `PERSON_NAME`, `INTERVIEWER`, `STATE_FIPS`: empty on all 100. The name only lives in `TITLE` and `SUBJECTS`.
- `LOC_ITEM_ID` runs 99615220 to 99615444. That is **225** numbers. We hold **100**. Exactly 100 rows, one run ID, flagged `is_sample: true` in the inventory: a one-page API pull.
- S06: landing holds the same 100. No fuller copy anywhere in the warehouse.

**Time check:** no real time. `INTERVIEW_DATE` is January 1 on every filled row: 97 × 1937, 1 × 1938, 2 blank.

**Peer check:** by state (read from `SUBJECTS`), **70** Texas, **20** Alabama, 3 Mississippi, 3 North Carolina, 2 Arkansas, 1 Ohio, 1 Indiana.
- Dull explanation: this is the first page of the photo set, and the photo set leans Texas. Nothing to rank.

**Duplicates:** 8 titles appear twice (16 rows). Each pair has its own LOC ID and its own image file. Two prints of the same sitter. Not a double load.

**Traps (for the ledger):**
- `STATE` is a real state on only **36** rows. It holds a **city** on **38** (Eufaula 10, Fort Worth 7, Beaumont 6...) and "united states" on **26**. The inventory lists `STATE` as this table's join key. It is not one.
- The catalog name "Born in Slavery ... narratives" oversells it. The typed narratives are not in the warehouse at all.

**What a hit would mean / what a miss means:** a hit needed text or a count. There is neither. A miss here says nothing about the WPA collection; it says the loader took one page of photos.
