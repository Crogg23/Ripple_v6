**The trap**
- CT's 8 counties (09001-09015) match nothing. 136 drug-poisoning rows (1999-2015) and 336 injury rows (7 periods) fall off the map.
- Join either CDC table to CB_COUNTY or DIM_COUNTY and **Connecticut vanishes**. DIM_COUNTY puts 3,605,944 people there.
- The drug-poisoning file also carries 7 retired codes: 5 old Alaska areas (02201, 02232, 02261, 02270, 02280), Shannon County SD (46113), Bedford city VA (51515).
  - All told, 253 of 53,387 county rows (0.5%) don't land.
- The injury file also carries 02261 Valdez-Cordova.

**Hit means:** a CT ranking built through this table is wrong: CT drops out, or shows up empty.
**Miss means:** nothing. The table itself is clean.
**Boring:** Census swapped CT counties for planning regions in 2022. CDC data before that uses the old codes. Nobody's wrong; the vintages don't line up. *(From memory: Census publishes a CT county-to-region crosswalk. I didn't check for it in the warehouse.)*

**Other traps**

## 3. ITIS NODC IDs (old NOAA species codes): **skip**

**Checked**
- S09: 209,565 rows. 209,565 distinct TSNs. One load run.
  - Every update date falls in June 1996 - March 1997. A frozen crosswalk.
  - TSNs run 50 to 209,644 with only 30 gaps.
  - The first rows read like a tree: `02` → TSN 50, `0202` → 51, `020201` → 52. Looks like ITIS numbered its first names straight off the NOAA list.
  - Not a row-number column: eyeball S10 shows real names. `8708010504` → Cephaloscyllium isabellum (a shark). `5512020811` → Fusconaia subrotunda (a mussel). `921301` → Ochotonidae (pikas). *(Common names from memory.)*
- S10, join to `ITIS_TAXONOMIC_UNITS`: every row lands.
  - **57,878 of 209,565 (27.6%) now point at names that are no longer accepted.** 151,687 point at accepted names.
- S14, the NOAA code is **not unique**: 178,951 codes for 209,565 rows.
  - 21,462 codes carry 2+ names (52,076 rows).
  - 19,166 of those: one accepted name plus its old synonyms. Expected.
  - 455 codes point at 2+ accepted names. 1,841 point at none.
  - Top: `3274015903` → 29 pussytoes (Antennaria) names. 27 not accepted, 2 accepted: Antennaria alpina and Antennaria X macounii.

**Hit means:** you can turn an old NOAA survey species code into a current ITIS name.
**Miss means:** nothing. It's a crosswalk.
**Routing rule:** NOAA code → TSN → `SYNONYM_LINKS` → accepted TSN. Skip the synonym hop and 27.6% of lookups land on a dead name.

**Traps**
- NODC_ID → TSN is many-to-many-ish. Don't treat the NOAA code as a key without deduping.
- The battery summed TSN again ("sum 22.0B"). Meaningless.
