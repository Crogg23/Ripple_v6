===== HEALTH__FED_CMS_NPPES ['cols', 'summary', 'row']
summary Every US health care provider with a National Provider Identifier, all 9.6 million doctors, nurses, clinics, pharmacies and suppliers, with names, addresses, specialties and licenses.
row One provider: one person or organization that holds one NPI.
   NPI :: The doctor's or clinic's 10-digit National Provider Identifier, stored as text. Some tables leave it mostly blank or empty, and the SAM exclusions table uses 0000000000 as a filler.
   PROVIDER_FIRST_NAME :: The provider's first name.
   PROVIDER_MIDDLE_NAME :: The provider's middle name or initial. Often blank.
   LAST_UPDATE_DATE :: The date the record was last updated at the source.
   NPI_DEACTIVATION_DATE :: The date the provider's 10-digit national ID was shut off. Almost always blank.
   CERTIFICATION_DATE :: The date the facility was certified to take Medicare. In the NPI registry it is when the provider last confirmed their record.
   _INGESTED_AT :: When this row was loaded into the warehouse. Usually a date and time, but some tables store a long number counting microseconds since 1970, and a few hold broken dates with impossible years like 56645
   _SOURCE_RUN_ID :: A label for the load run that brought this row in, usually a random ID but sometimes a name like manual-1785965790 or a file name. One table can hold many run IDs. Added by your pipeline, not the sour
   _SRC_SHA256 :: A fingerprint of the source file this row came from, used to spot a changed file. Some tables hold the placeholder "streamed-see-source-zip" or leave it empty. Added by your pipeline, not the source.
   ENTITY_TYPE_CODE :: 1 or 2: 1 marks a person and 2 an organization; the counts line up with the person and organization name columns. Blank on a few hundred thousand rows.
   REPLACEMENT_NPI :: The newer NPI that replaced this one. Almost always blank; filled on only about 80 rows.
   EMPLOYER_IDENTIFICATION_NUMBER_EIN :: Meant to hold the organization's federal tax ID, but it is empty in this table.
   PROVIDER_ORGANIZATION_NAME_LEGAL_BUSINESS_NAME :: The organization's legal business name, like WALGREEN CO. Filled only for organizations, so blank on most rows.
   PROVIDER_LAST_NAME_LEGAL_NAME :: The person's legal last name. Filled only for individual providers.
   PROVIDER_NAME_PREFIX_TEXT :: Name prefix like DR., MRS. or MS. Mostly blank.
   PROVIDER_NAME_SUFFIX_TEXT :: Name suffix like JR., II or III. Mostly blank.
   PROVIDER_CREDENTIAL_TEXT :: The person's credentials as typed, like MD, M.D., RN or LCSW. Free text, so the same degree is spelled many ways.
   PROVIDER_OTHER_ORGANIZATION_NAME :: Meant to hold another name the organization uses, but every filled row just says <UNAVAIL>. Mostly blank.
   PROVIDER_OTHER_ORGANIZATION_NAME_TYPE_CODE :: Type code for the other organization name; always 6 when filled, and the code needs a lookup. Mostly blank.
   PROVIDER_OTHER_LAST_NAME :: Another last name the person has used, such as a maiden name. Mostly blank.
   PROVIDER_OTHER_FIRST_NAME :: First name that goes with the person's other name. Mostly blank.
   PROVIDER_OTHER_MIDDLE_NAME :: Middle name or initial that goes with the person's other name. Mostly blank.
   PROVIDER_OTHER_NAME_PREFIX_TEXT :: Prefix like DR. or MS. on the person's other name. Mostly blank.
   PROVIDER_OTHER_NAME_SUFFIX_TEXT :: Suffix like JR. on the person's other name. Almost always blank.
   PROVIDER_OTHER_CREDENTIAL_TEXT :: Credentials typed with the person's other name, like MD or RN. Mostly blank.
   PROVIDER_OTHER_LAST_NAME_TYPE_CODE :: A code for what kind of other name this is: 1, 5, 2 or 3; the codes need a lookup. Mostly blank.
   PROVIDER_FIRST_LINE_BUSINESS_MAILING_ADDRESS :: First line of the provider's mailing address. Many providers share one address, including P.O. boxes like PO BOX 7004.
   PROVIDER_SECOND_LINE_BUSINESS_MAILING_ADDRESS :: Second line of the mailing address, usually a suite number. Mostly blank.
   PROVIDER_BUSINESS_MAILING_ADDRESS_CITY_NAME :: City of the provider's mailing address.
   PROVIDER_BUSINESS_MAILING_ADDRESS_STATE_NAME :: State of the mailing address, mostly as two letters. Over a thousand distinct values, so foreign and misspelled entries are mixed in.
   PROVIDER_BUSINESS_MAILING_ADDRESS_POSTAL_CODE :: ZIP code of the mailing address, often 9 digits run together, stored as text.
   PROVIDER_BUSINESS_MAILING_ADDRESS_COUNTRY_CODE_IF_OUTSIDE_U_S :: Country of the mailing address as two letters; US on nearly every row.
   PROVIDER_BUSINESS_MAILING_ADDRESS_TELEPHONE_NUMBER :: Phone number for the mailing address, 10 digits as text. Many providers share one number.
   PROVIDER_BUSINESS_MAILING_ADDRESS_FAX_NUMBER :: Fax number for the mailing address, 10 digits as text. Mostly blank.
   PROVIDER_FIRST_LINE_BUSINESS_PRACTICE_LOCATION_ADDRESS :: First line of the street address where the provider actually practices.
   PROVIDER_SECOND_LINE_BUSINESS_PRACTICE_LOCATION_ADDRESS :: Second line of the practice address, usually a suite number. Mostly blank.
   PROVIDER_BUSINESS_PRACTICE_LOCATION_ADDRESS_CITY_NAME :: City where the provider practices.
   PROVIDER_BUSINESS_PRACTICE_LOCATION_ADDRESS_STATE_NAME :: State where the provider practices, mostly as two letters. Over a thousand distinct values, so foreign and misspelled entries are mixed in.
   PROVIDER_BUSINESS_PRACTICE_LOCATION_ADDRESS_POSTAL_CODE :: ZIP code of the practice address, often 9 digits run together, stored as text.
   PROVIDER_BUSINESS_PRACTICE_LOCATION_ADDRESS_COUNTRY_CODE_IF_OUTSIDE_U_S :: Country of the practice address as two letters; US on nearly every row.
   PROVIDER_BUSINESS_PRACTICE_LOCATION_ADDRESS_TELEPHONE_NUMBER :: Phone number at the practice location, 10 digits as text. Many providers share one number.
   PROVIDER_BUSINESS_PRACTICE_LOCATION_ADDRESS_FAX_NUMBER :: Fax number at the practice location, 10 digits as text. Mostly blank.
   PROVIDER_ENUMERATION_DATE :: The date the provider was first given this NPI. The earliest dates are in 2006 and 2007, when the system started.
   NPI_DEACTIVATION_REASON_CODE :: Meant to hold why an NPI was shut off, but it is empty in this table.
   NPI_REACTIVATION_DATE :: The date a shut-off NPI was turned back on. Almost always blank.
   PROVIDER_SEX_CODE :: The person's sex as F, M, X or U. Filled only for individual providers.
   AUTHORIZED_OFFICIAL_LAST_NAME :: Last name of the person who signs for the organization, like its owner or president. Filled only for organizations.
   AUTHORIZED_OFFICIAL_FIRST_NAME :: First name of the person who signs for the organization. Filled only for organizations.
   AUTHORIZED_OFFICIAL_MIDDLE_NAME :: Middle name or initial of the person who signs for the organization. Mostly blank.
   AUTHORIZED_OFFICIAL_TITLE_OR_POSITION :: Job title of the person who signs for the organization, like OWNER, PRESIDENT or CEO. Free text.
   AUTHORIZED_OFFICIAL_TELEPHONE_NUMBER :: Phone number of the person who signs for the organization, 10 digits as text.
