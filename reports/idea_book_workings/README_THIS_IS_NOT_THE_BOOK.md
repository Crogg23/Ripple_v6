# This folder is the parts bin. It is not the book.

The book is one file at the repo root: `THE_IDEA_BOOK.md`. Read that. Edit that.

What is in here, and why it is kept:

| files | what they are | when you would open one |
|---|---|---|
| `ch_*.md` | the eight chapters as separate files, frozen 2026-09-13 | never; the root book holds the same 2,230 rows. These go stale the moment the book is edited |
| `extract_*.md` | the five raw piles the book was merged from | to see an idea in its original wording |
| `xw_*.csv` | id maps, book id to raw-pile id | to walk a book row back to its source row |
| `_BRIEF.md`, `_MERGE_BRIEF.md` | the instructions the build agents were given | to see how the book was made |
| `top3_holy_fuck_sql_2026-09-13.md` | three picked ideas with full SQL, none run | when running M-056, P-147 or P-062 |

Folder renamed from `reports/idea_book` on 2026-09-18 so nobody mistakes it for the book.
