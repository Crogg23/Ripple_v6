What am I looking at?

A map of which tables in the warehouse can be joined to which other tables, and on what column — built by actually running the joins against live data, not by guessing from column names.

Why this exists

560+ government data sources, each built by a different agency that never talked to the others. The same hospital shows up as a different-looking row in Medicare's files, OSHA's files, and the federal contracts file. Nothing tells you those rows are the same hospital — except that they all print the same official ID number somewhere. This handbook is that list: which tables share a real ID number, and how well the values actually lined up when we checked.

How to read a connection

Every row says: this table and that table both have a column holding the same kind of ID number. We counted how many of the ID values in one table also show up in the other. That percentage is the confidence score. Click any row to see the exact join, the raw counts behind it, and a copy button for the SQL.
