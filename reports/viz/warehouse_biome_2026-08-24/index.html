How to read it: each circle is one table in LIBRARY_MARTS, radius scaled to √(row count) so area tracks size honestly. Color groups tables by domain schema — health, finance, environment, and so on. The biggest single table, DEA ARCOS (controlled-substance shipping records, 178.6M rows), sits inside Health; SEC 13F institutional holdings and FEC itemized contributions anchor Finance. This is raw landed volume, not data quality or completeness — a big bubble means a lot of rows loaded, nothing more. Live row counts pulled from LIBRARY_MARTS.INFORMATION_SCHEMA.TABLES, 2026-08-24.
