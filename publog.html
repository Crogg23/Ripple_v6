PUB LOG® - Public Logistics Data

Download PUB LOG® (.ZIP) Download PUB LOG® (.ZIP): https://publogstorage.blob.core.windows.net/publog/PublogDVD.zip

The PUB LOG® .ZIP (updated monthly) and individual files and can also be downloaded from the Federal Logistics Information Services (FLIS) Data Electronic Reading Room.

PUB LOG® Information

PUB LOG® is a Logistics Information Services product intended for use by public entities requiring National Stock Number (NSN) information and other cataloging information including Federal Supply Classification (FSC) data and Commercial and Government Entity (CAGE) codes.

PUB LOG® delivers publicly releasable logistics information. It is an interactive product available for free downloads that are updated monthly. It can be installed on users' workstations or local area network (LAN) using Integrated Mobile Database (IMD) software, integrating multiple database sources. These databases are mastered together into a single cohesive product.

Check the FLIS Data Reading Room for download updates and instructions. PUB LOG® downloads do not require a subscription or Common Access Card (CAC) authorization.

Please review the PUB LOG® download and installation instructions to learn more about accessing the PUB LOG® application.

Downloads are available to:

  • The United States government
  • Foreign Military Sales
  • Other foreign national customers
  • The private sector

What PUB LOG® Provides

  • Federal Logistics Information System (FLIS) Data
    • Non-restricted National Stock Number (NSN) data
  • Five searchable NSN based products
    • FLIS Data- Contains all active non-restricted National Stock Numbers (NSN) and their associated supply data located in the FLIS
    • Characteristics Data (CHAR DATA)
      • Search by:
        • Federal Supply Class (FSC)
        • National Item Identification Number (NIIN)
        • Item Name
        • Characteristics
        • Medical_Name
        • Common_Name
    • Demilitarization Data (DEMIL) - Determine what restrictions (if any) apply in the demilitarization of disposable materiel
    • Master Cross Reference Data (MCRD) - NSNs, reference numbers, and Commercial and Government Entity (CAGE) Codes cross-referenced to each other, supplemented with related data
    • Management Data Interchangeability and Substitutability (MDI&S) - Determine the interchangeability and/or substitutability of items of supply
    • H-Series
      • Combination of cataloging handbooks:
        • H2, Federal Supply Classification (FSC)
        • H3, Department of Defense (DOD) Ammunition Codes
        • H5, Corporate Complex Data
        • H6, Federal Item Name Directory (FIND)
    • Search features
      • Search Batch
      • Search Interactive
      • Structured Query Language (SQL)

Restricted data such as service unique data, proprietary data and North Atlantic Treaty Organization (NATO) data is not included in PUB LOG®.

PUB LOG® FLIS Data Information

Federal Logistics Information System (FLIS) Data is part of the PUB LOG® product. It provides unrestricted information for each National Stock Number (NSN) in the Federal Catalog System (FCS).

FLIS Data contains information that describes the NSN to include:

  • Characteristics
  • National Motor Freight Classification (NMFC)
  • Precious Metals Indicator Code (PMIC)
  • Demilitarization Code
  • Criticality Code

FLIS Data allows users to search by:

  • National Item Identification Number (NIIN)
  • Federal Supply Class (FSC)
  • Item Name Code (INC)
  • Item Name (ITEM_NAME)

Each of the above search elements is further defined in the PUB LOG® product. Multiple word elements require an underscore between each word searching for definition (i.e. Item Name should be typed Item_Name).

PUB LOG® FLIS Characteristics Data (CHAR DATA)

Characteristic Data (CHAR DATA) is part of the PUB LOG® product. It provides characteristics information for each National Stock Number (NSN) in the Federal Catalog System (FCS) and is used to identify an NSN when an item name or characteristic(s) is known.

CHAR DATA contains information that describes the NSN to include:

  • Item Name
  • Environmental Attribute Codes (ENACs)
  • Master Requirement Code (MRC)
  • Requirements Statement
  • Clear Text Reply

CHAR DATA allows users to search by:

  • Federal Supply Class (FSC)
  • National Item Identification Number (NIIN)
  • Item Name (ITEM_NAME)
  • Any characteristic (CHARACTERISTICS)
  • ​Medical_Name
  • Common_Name

Each of the above search elements is further defined in the PUB LOG® product. Multiple word elements require an underscore between each word when
searching for definition (i.e. Item Name should be typed Item_Name.)

PUB LOG® Master Cross-Reference Data (MCRD) Information

Master Cross-Reference Data (MCRD) is part of the PUB LOG® product. It contains National Stock Numbers (NSN), reference numbers, and Commercial and Government Entity (CAGE) Codes cross-referenced to each other and supplemented with related data.

MCRD contains information that cross-references the NSN to include:

  • Part Number/Reference Number
  • Commercial and Government Entity Code (CAGE)
  • Source of Supply (SOS)
  • Automatic Data Processing Equipment (ADP)
  • Precious Metal Indicator Code (PMIC)

MCRD allows users to search by:

  • Federal Supply Class (FSC)
  • National Item Identification Number (NIIN)
  • Part Number (PARTNBR)
  • CAGE
  • Name (NAME)
  • Item Name Code (INC)

Each of the above search elements is further defined in the PUB LOG® products. Multiple word elements require an underscore between each word when searching for definition (i.e. Item Name should be typed Item_Name).

NSNs that contain any proprietary information (indicated by MRC PRPY) are excluded.

Management Data Interchangeability and Substitutability (MDI&S)

Management Data Interchangeability and Substitutability (MDI&S) is part of the PUB LOG® product and represented by the MGMT tab. The MD portion is designed to provide users with supply management data on all National Stock Numbers (NSN) recorded in the Catalog Management Data (CMD) segment of the Federal Logistics Information System (FLIS) database. The I&S portion provides a reference source for determining the interchangeability and/or substitutability of items of supply.

The MDI&S contains information that describes the NSN to include:

  • Master Requirements Code (MRC)
  • Requirements Statement
  • Clear Text Reply
  • Automatic Data Processing Equipment (ADP)
  • Precious Metal Indicator Code (PMIC)
  • Primary Inventory Control Activity (PICA)
  • Item Name
  • Service Related NSN
  • Order-of-Use Code (OOU)
  • Jump-to Code (JTC)
  • Phrase Code (PC)

 The MDI&S MGMT tab allows users to search by:

  • Federal Supply Class (FSC)
  • National Item Identification Number (NIIN)
  • Item Name (NAME)
  • Source of Supply (SOS)
  • Acquisition Advice Code (AAC)

Each of the above search elements is further defined in the PUB LOG® product. Multiple word elements require an underscore between each word when searching for definition (i.e. Item Name should be typed Item_Name). Note: NSNs that contain any proprietary information (indicated by MRC PRPY) are excluded from this publication.

PUB LOG® H-Series Information

The H-Series is part of the PUB LOG® download product. It consists of six Supply Handbook Publications:

H2, Federal Supply Classification (FSC)

  • Provides information about the FSC and Federal Supply Group (FSG)
  • Allows users to search  by:
    • FSG
    • FSC
    • FSG Title (FSG_TITLE)
    • FSC Title (FSC_TITLE)

H3, Department of Defense (DOD) Ammunition Codes

  • Provides uniform, centrally assigned code numbers for generic descriptions of items of supply identified in two FSCs within the Federal Catalog System (FCS)
    • 13 (Ammunition and Explosives)
    • 14 (Guided Missiles)
  • Allows users to search by:
    • FSC
    • Department of Defense Identification Code (DODIC)
    • DODAC
    • Item Name (ITEM_NAME)

H5, Corporate Complex Data

  • Shows the corporate complex structure of commercial entities and affiliated companies assigned a five-digit CAGE Code or NATO Supply Code for Manufacturers
  • Allows users to search by:
    • Association CAGE (ASSOCIATION_CAGE)
    • CAGE
    • COMPANY
    • CITY
    • STATE
    • Zip Code (ZIP)
    • State (PROVINCE)
    • Postal Zone (POSTAL_ZONE)
    • COUNTRY

H6, Federal Item Name Directory (FIND)

  • Provides item name data for the development and maintenance of item identifications within the FCS to include:
    • Approved Item Names (AINs)
    • Basic and Colloquial Names with definitions and associated FSCs
    • Condition Codes
    • Federal Item Identification Guides (FIIGs) Applicability Key
    • Concept Number
      • Item Name Codes (INCs)
    • Allows users to search   by:
      • INC
      • Item Name (ITEM_NAME)
      • FIIG
      • FIIG 4 (FIIG_4)
      • FSC
      • Integrated Materiel Manager (IMM)

Each of the above elements is further defined in the PUB LOG® product. Multiple word elements require an underscore between each word when searching for definition (i.e. Item Name should be typed Item_Name).
